# Admin

Khu vực quản trị gồm các feature con:

- `dashboard`: thống kê và biểu đồ.
- `customers`: quản lý khách hàng.
- `staff`: quản lý nhân viên/thợ.
- `services`: quản lý dịch vụ salon.
- `products`: quản lý sản phẩm bán kèm.
- `appointments`: quản lý lịch hẹn.
- `shifts`: quản lý ca làm việc và ngày nghỉ.
